# Source-neutral editor workbench

The user selected a multi-instance document workbench with provider-owned locations, independent automatic update and save preferences, and explicit three-way conflict resolution. The editor compares exact canonical source text through content hashes and keeps base, local and latest source snapshots. A source owns text normalization, versions, watching, conditional writes and optional location selection.

The right-sidebar workbench owns tabs, activation and close gestures. The viewer contributes one static renderer and creates an instance for each exact Session, source and resource identity. Closing a dirty instance requires confirmation.

The separate file-manager plugin owns authenticated user filesystem access, filesystem document sources, tree presentation, source-location selection and Chat file routing. Filesystem UI actions follow the authenticated user rather than agent filesystem policy. The viewer package contains no workspace Host Remote or built-in filesystem source.

The compatibility patch remains repository evidence for the cross-repository contribution. Viewer setup and uninstall do not apply or reverse Harness source. File-manager installation owns any continuing Host compatibility work and its receipt.
