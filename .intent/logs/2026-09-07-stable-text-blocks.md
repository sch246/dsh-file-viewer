# Stable text block implementation evidence

The selected design cuts normal CodeMirror input over to UTF-16 ranges and one shared immutable block document. It removes the editor's retained full string and per-key doc.toString, the panel's full-string synchronization, and the service's whole-document idle hash. Block byte lengths remain canonical UTF-8 metadata. Filesystem segmented reads deliver canonical blocks directly, and remote line patches retain unaffected blocks. Raw transport SHA-256 and canonical block SHA-256 identify different content.

Review identified two relevant timing conditions: asynchronous canonical hashing between decoder advancement and chunk delivery would lose a stopped prefix; canonical blocks are therefore constructed synchronously and hashed at completed document validation. A React-delayed peer effect could use old coordinates after another view changed the service; editor subscriptions now synchronize document transactions immediately, with the submitting editor excluded until its callback records the resulting snapshot. Weak historical ancestry has a shared-block-anchor fallback, so garbage collection does not trigger full-text replacement during ordinary editing.

Implementation stayed in `/root/dsh-block-edit/viewer`. Dependencies were installed with `DSH_USER_FILES=/root/dsh-block-edit/user-files/packages/dsh-user-files DSH_SIDEBAR=/root/dsh-decoupling-apply/sidebar/packages/dsh-right-sidebar pnpm run install:local`; `DSH_CHECKOUT=/root/deepseek-harness` selected the Host for builds. No Host source, profile, live deployment, provider source or restart was changed. Parent owns publishing and activation.

The focused service command below passed 24 tests, including byte/code-point boundaries, cross-block deletion, partition-independent undo, unchanged block identity/hash reuse, skipped-history view ranges, real service typing with a throwing full-text getter, idle latest-pending scheduling, segmented resume, final integrity, delta save/update and invalid Config. Editor/inline-comparison checks passed 16 tests; panel checks passed 11 tests covering synchronous peer edits before React flush, independent presentation and subscription disposal. `DSH_CHECKOUT=/root/deepseek-harness pnpm run build` passed after integration, including Host and both Client TypeScript programs plus generated Remote and bundles. `DSH_CHECKOUT=/root/deepseek-harness pnpm run typecheck` passed; the 3 model/service-input tests passed again after adding the short-interior-transfer-block assertion. The first delta save run exposed a test's single-microtask assumption after block checks became serialized; the fixture now waits for the explicit zero-delay fake-clock work before evaluating its save result.
