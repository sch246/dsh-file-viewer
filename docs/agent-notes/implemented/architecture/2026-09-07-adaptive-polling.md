# Adaptive polling and guarded delta updates

The filesystem source owns one browser background permit shared by text and byte watches. A cycle includes the Remote request and its awaited document consumer, including range validation, complete hash verification and state application. Other subscriptions skip rather than queue. Size-specific idle intervals, measured cycle duration and capped exponential failure backoff control the next request. Manual actions bypass this admission. The provider separately admits a bounded number of background delta computations so independent browser clients cannot create an unbounded server queue.

User-files owns the canonical baseline cache, current-disk snapshot, bounded jsdiff computation and wire-byte threshold. Its pure text-patch leaf owns LF line tokens, insertion context and guarded application for both Host and browser; CodeMirror owns presentation only. The shared helper replaces the editor-only save differ. Cache byte accounting bounds retained canonical strings, not all temporary objects or heap. A stat shortcut avoids unchanged content reads, with the explicit limitation that writes preserving every observed stat field are invisible to that shortcut.

The browser's verified Source pair identifies each delta baseline. All old-range hashes and the complete new Source hash must match before publication to document state. The browser does not advance that pair on failed validation. Local applies remote ranges only when they match at exact coordinates against its common Base; unrelated local edits remain dirty against the advanced Source. Conflicts preserve Local and require manual comparison. Editor transactions map selection and undo positions while retaining scroll.

Unavailable baselines, excessive serialized patches and exhausted diff budgets stop background work until explicit Update. Manual Update tries a delta first and can fall back to a complete approved read; automatic checks cannot take that fallback. A successful manual refresh reattaches stopped watches. A saved-with-other-changes result retains the old verified Source pair marked stale, keeping it usable for a later delta without claiming that its text matches the new server hash. Viewer requires independently versioned user-files ^0.1.4; other consumers keep their compatible ranges.
