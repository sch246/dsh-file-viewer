# Shared text blocks and transaction input

The document service owns immutable canonical text snapshots built from stable variable blocks. CodeMirror emits original-document UTF-16 transaction ranges; document edits replace only intersected blocks and locally rebalance short or oversized results. Blocks track canonical UTF-8 byte lengths independently of their string offsets. Config owns ordered 0.5/1/2 MiB defaults; Unicode code points remain whole when splitting.

Filesystem transport validates raw download hashes and decodes UTF-8/CRLF statefully. It supplies canonical block objects to the document accumulator synchronously with each decoded chunk. Completion merges short interior fragments and verifies the full canonical hash plus block hashes. Decoder advancement and chunk delivery have no asynchronous hash step between them, so cancellation cannot consume an undelivered prefix. Base, Local and Source reuse the received blocks; validated remote line ranges edit Source and Local blocks without repartitioning the complete text.

Normal input and idle synchronization checks never serialize, encode, hash or diff the full document. One background check hashes only dirty blocks, retaining the latest pending edit and respecting the large-document idle delay. Exact comparison skips shared blocks and compares remaining canonical text independently of partitioning. Equal content can reuse its known canonical hash; block hashes are not combined into a standard SHA-256. Complete canonical SHA-256 remains authoritative at load, save and update.

Each editor synchronously subscribes to shared document changes, excluding its own active submission. Peers receive transactions before another input can use stale positions, while selection, undo and scroll stay view-owned. Views catching up after an unavailable historical chain use unchanged block identities as anchors and transfer only changed gaps. Full-text access remains explicit through source APIs, manual save preparation, browser drafts, comparison and initial editor construction; the snapshot text getter is nonenumerable so metadata spreads cannot flatten it.
